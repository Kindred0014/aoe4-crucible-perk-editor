## 中文

1. 游戏里打开 **炼狱 → 天赋界面**。
2. 双击 `AOEIV-perk-editor.exe`
3. 填**游戏界面上显示的点数** → 点绿色按钮。
4. 回游戏：**买一个天赋（或退一个）**，然后**退出炼狱界面回主菜单**
5. 重启游戏确认点数还在。

注意
- 打不开游戏进程时，用管理员身份运行。
- 只填游戏里真实显示的数字。乱写会炸游戏。
- 仅限单人离线使用，不要用于多人或排位。风险自负。

## English

1. In game, open the **Crucible → Perk** screen.
2. Double-click `AOEIV-perk-editor.exe`
3. Type in **the points shown in the game** → click the green button.
4. Back in the game: **buy one perk (or refund one)**, then **leave the Crucible screen and go back to the main menu**
5. Restart the game and make sure that the points are still there.

Note
- If can not open the game process, run as administrator.
- Only type in the number actually shown in the game, or the game will crash.
- Single-player and offline use only — not for multiplayer or ranked play. Use at your own risk.
